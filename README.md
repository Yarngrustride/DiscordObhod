> [!WARNING]
>
> ### Реакция антивируса
>
> Для работы zapret нужен WinDivert, который перехватывает и фильтрует сетевой трафик. Поэтому антивирус может отреагировать на него.
> WinDivert способен использоваться как безопасными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и переносится в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите проверку PUA, то есть потенциально нежелательных приложений. Например, Kaspersky предлагает параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Лучше настроить исключение, если вы понимаете последствия, а при сомнениях отключить обнаружение PUA.

## ⚙️ Использование

1. Настройте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от варианта "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную введите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот способ рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/Yarngrustride/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот шаг не требуется.

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Чтобы подобрать рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск используйте **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*.

## ℹ️ Назначение файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** показывает состояние обхода и служб: стратегии автозапуска и WinDivert.
  - **`Game Filter`** переключает режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние указано в скобках: включено или выключено.
  - **`IPSet Filter`** меняет режим обработки сервисов из `ipset-all.txt`.  
  Это полезно при диагностике ресурса, который без zapret работает, а с ним нет.  
  В скобках отображается одно из состояний:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - IP проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет текущий фейк другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает из репозитория актуальную версию `ipset-all.txt`.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты из `utils/targets.txt`.
    - `DPI checkers` тестирует DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe, отвечающий за обход.  
Если его нет, обратитесь к [#522](https://github.com/Yarngrustride/zapret-discord-youtube/issues/522).

### Рабочая стратегия не найдена

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированные данные в конец `hosts` либо замените ими ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. При неудаче используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Yarngrustride/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение определённого варианта может привести к тому, что ранее рабочая стратегия перестанет помогать.
> Здесь доступно много разных стратегий. Если ни одна не подходит, создайте новую на основе существующей и измените её параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.
- Убедитесь, что адрес нужного ресурса присутствует в списке доменов или IP-адресов.
- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и остальные стратегии.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/Yarngrustride/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Затем выберите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце нажмите Y.
- Удалите старый каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/Yarngrustride/zapret-discord-youtube/releases), например `zapret-discord-youtube-...`.
- Откройте свойства архива правой кнопкой мыши. Если внизу есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска. В пути не должно быть пробелов и специальных символов.
- Запускайте разные скрипты `general`, проверяя доступ к нужным ресурсам. Если интернет-ресурсы не открываются, завершите программу через значок замка в панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Для WinDivert нужна цифровая подпись драйвера в Windows 7

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows. Откройте её через Win+R и введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с ними.
- Если раньше всё работало, переберите остальные стратегии.
- См. также [#251](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте Discord после очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если сайт также не открывается, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/Yarngrustride/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Yarngrustride/tg-ws-proxy).
- Другой вариант - воспользоваться бесплатными MTProto-прокси из интернета.

### Не работают игры

Игры используют разные настройки, поэтому проверить и исправить каждую из них невозможно.

Попробуйте следующий общий порядок действий:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если этого недостаточно, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Лучше определить все IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Yarngrustride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Опишите её [в разделе issues](https://github.com/Yarngrustride/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены-исключения, например когда сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не нужно.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
